# v1-12 実装設計: デスクトップUIフロー

## 対象

- Issue #13
- Avalonia desktop UI
- UI表示・設計文言は日本語

## 画面構成

v1では操作を4段階へ整理する。

1. 素材
2. 話者・分類
3. 品質
4. 学習・Export

フォルダ入力を主導線として大きく表示し、単一ファイル入力は補助導線とする。

## 素材

- フォルダから新規Voice Projectを作成
- 単一ファイル入力
- スキャン件数・準備完了件数・失敗件数
- 対応素材一覧
- 処理進捗
- エラー時の再試行

「解析を実行」から以下を順次実行する。

- 音声前処理
- 話者解析
- Speech / Singing分類
- Universal Voice Dataset生成
- 50音・音素カバレッジ診断
- 歌唱品質診断

## 話者・分類

話者ごとに次を表示する。

- 表示名
- 使用可能時間
- 学習対象選択
- 歌唱 / トーク / 両方

複数話者を選択してクラスタ統合できる。
代表サンプルはOSの既定音声プレイヤーで開く。

Speech / Singing分類結果は一覧表示し、選択segmentをSpeechまたはSingingへ手動修正できる。
segment除外も同じ画面から行う。

## 品質

50音・音素カバレッジでは「良好 / 注意 / 不足」を日本語表示する。

歌唱品質では以下を要約する。

- 音域
- pitch reliability
- 品質レベル
- 品質警告

警告は学習をブロックせず、ユーザー判断用として表示する。

## 自動補完・補正

デフォルトONとする。

説明文では以下を明示する。

- 元録音を書き換えない
- ONでは補完・補正済み学習用ビューを利用する
- OFFでは観測素材のみを利用する

## 学習準備

選択話者ごとの用途指定からTrainingJobPlanningServiceを呼び出す。
生成したjobはVoice Projectのtraining-jobs metadataへ保存する。

v1-12時点ではUIからの学習ジョブ作成と状態・成果物表示までを共通UIへ接続する。
DiffSinger / Style-Bert-VITS2固有の実trainer・Exporter入力フォームは各Exporter実機検証と合わせて仕上げる。

## エラー・再試行

UI操作で例外が発生した場合は下部statusへ日本語メッセージを表示し、再試行ボタンを有効にする。
