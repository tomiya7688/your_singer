# 設計書の索引

Issueを実装する人が、**担当Issueの実装パケットだけを開いて着手できる**ようにするための入口です。仕様の正本は `docs/` の各文書で、ここは探し方と、Issueとの対応を示します。実装前の確認は[着手前チェック](../../dev-guidelines/implementation-ready.md)に従います。

## 読む順番

1. 担当Issueの本文を読む。
2. 下の表で、担当Issueの**実装パケット**を開く（自分のIssueの節だけ読めばよい）。
3. パケットが指す設計正本を、その節だけ読む。全文を先に読まない。
4. パケットの「要決定」を[決定記録](decisions.md)で確認する。状態が「待ち」「実装内」の項目は、記録の指示に従う。
5. [着手前チェック](../../dev-guidelines/implementation-ready.md)の7項目を満たしてから実装する。

## パケットの形式と更新

各Issueの節は、目的・先行・触るもの（コードの実在確認つき: 既存/新規/不明）・契約・完了条件・テスト・非目標・要決定で構成します。実装を変えたPRは、該当するパケットも同じPRで更新します。パケットは設計の複製ではなく、実装の入口です。契約や式の本文は設計正本にあり、パケットは節名で参照します。
