# v1-14 実装設計: 回帰テストと学習入力の整合性

## 対象

Issue #15。入力走査、手動編集、学習入力の構築、品質診断、保存の回帰テストを整備する。
この段階は実モデル学習・外部推論・GUI操作を通すE2Eとは区別する。

## テスト構成

`tests/YourSinger.Process.Tests/` は .NET 10 / xUnit v3 を使用する。
`TestProject` が一時フォルダ、短いPCM WAV、明示した話者割り当て・分類・音素列・特徴ファイルを生成する。
音声認識や話者識別を実行した結果ではない。話者が複数ファイルへ跨るテストも、保存済み割り当ての維持を検証するものであり識別精度の試験ではない。

```sh
dotnet test tests/YourSinger.Process.Tests/YourSinger.Process.Tests.csproj --configuration Release --logger "trx;LogFileName=regression.trx" --results-directory TestResults
python -m compileall -q src/process/YourSinger.Process/processing/ml/worker/your_singer_ml
```

GitHub ActionsはWindowsとLinuxの双方でアプリのビルドと回帰テストを実行する。
成功・失敗にかかわらずTRXを14日間保存する。Pythonは別ジョブで構文を検査する。
Python構文確認は依存パッケージの実行や学習を検証しない。

## 今回修正する境界

### 最新の手動編集を学習入力へ適用

`TrainingDatasetSnapshotService` は共通音声データを読み、現在の話者割り当て、話者特徴、分類、手動除外を学習用の投影へ適用する。
元の共通音声データは保存し直さず、除外された区間も観測結果から削除しない。
除外は自動補完・補正ON/OFFのどちらでも有効。OFFにしてもユーザーの除外・統合・分類修正は取り消さない。

補正サービス、ジョブ計画、歌唱・トークの学習用データ構築でこの境界を共有する。
ML処理を再実行する必要はない。

### 話者統合と使用時間

前処理結果に保存された `end_sec - start_sec` を区間ごとに集計する。
区間の件数比率で時間を近似しない。統合後の総時間、除外後の使用可能時間を再計算する。
話者重心は統合前の区間時間を重みとして統合し、正規化する。
必要な前処理結果が欠ける場合は、誤った時間を保存せず日本語のエラーにする。

### データ指紋

共通データのスキーマ版・処理版、補正処理版、設定、区間の全メタデータ、補正記録からSHA-256を作る。
区間IDなどを固定順に並べ、地域設定に依存しないJSON数値表現を使う。生成日時は含めない。
ジョブごとに話者・用途・区間一覧も含めるため、異なる話者や用途の入力は区別できる。

指紋の対象はメタデータと既存のCacheKeyである。特徴ファイルの内容だけを外部で直接改変した場合の完全性検査は別途必要。
バイト単位のモデル再現性やGPU学習の決定性を保証するものではない。

### 古いジョブと不正入力

入力構築時に現時点の投影を作り、計画時の指紋と比較する。
除外、分類、話者、文字起こしなどが変わっている場合は、古い設定のまま続行せずジョブ再作成を要求する。
指紋方式変更前に作成した古いジョブも再作成が必要。

用途未指定、不明な用途、話者重複、空の学習入力は保存前に拒否する。
「両方」で一方の用途に素材がない場合は部分的なバッチを保存せず、用途の選び直しを案内する。
待機中から成功への飛び越しや、完了状態から実行中への巻き戻しを拒否する。
再学習には新しいバッチ・ジョブIDを付け、元の結果を保持する。

### 学習入力の公開

学習入力は同じ親フォルダの一時ディレクトリに作成し、完成後に移動して公開する。
コピー失敗・保存失敗・キャンセル時は作成途中の一時ディレクトリを除去する。
公開済みの入力は上書きしない。再実行は新しい学習ジョブで行う。
トーク用の相対音声パスはプロジェクトのルートを基準として解決する。
この保証は学習入力の構築についてのものであり、既存Exporterの全失敗経路を検証したものではない。

## Issue #15 の検証範囲

| 要件 | 自動テストで確認する範囲 | 未検証の範囲 |
| --- | --- | --- |
| 単一ファイル・フォルダ入力 | 拡張子、再帰走査、日本語パス、元素材不変 | 実素材からモデル生成までのE2E |
| 複数話者・ファイル跨ぎ | 保存済み割り当て、統合、除外、ジョブ分離 | ML話者識別の精度 |
| 会話・歌唱の振り分け | 分類修正から両Dataset Builderへの反映 | 実音声分類の精度 |
| 音素カバレッジ | 不足警告、全対象音素が十分な場合の診断 | 実音声の発音精度 |
| 補完・補正ON/OFF | 自動除外、設定保存、手動編集維持、指紋 | 欠損音素の実生成、条件間補間 |
| 差分再解析 | サイズ・日時が同じ内容変更、解析版変更 | 全MLステージのキャッシュ無効化 |
| 学習用途・再学習 | 用途別ジョブ、話者別設定、古いジョブ拒否 | 実Trainerによる学習完走 |
| エラー・成果物保護 | 保存キャンセル、コピー失敗、入力上書き拒否 | 全Exporter・ML子プロセスの異常終了 |
| 外部ソフト互換性 | 必須成果物欠落時の検証失敗、Registry | 有効なモデルの読み込み・実音声生成 |
