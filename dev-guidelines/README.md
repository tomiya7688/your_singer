# dev-guidelines — 開発参加者向け資料

このフォルダは、your_singer の開発に参加する人とAIエージェント(Claude Code、Codex、ChatGPT、Copilot)だけが読む資料を置く場所です。

## 文書の置き場所と読み手

| 場所 | 読み手 | 内容 |
| --- | --- | --- |
| `dev-guidelines/` | 開発参加者・AIエージェント | レビュー基準など、変更を作る・確認するための基準 |
| `docs/` | リポジトリオーナー・設計者 | 仕様、設計、実装計画、ロードマップ |
| `README.md` | 利用者 | プロジェクトの概要と使い方 |

利用者向けの文書とリポジトリオーナー向けの文書は混ぜません。開発参加者向けの基準を `docs/` や `README.md` に書かず、このフォルダに置いてください。

- 関連(リポジトリ直下): [`AGENTS.md`](../AGENTS.md) 共同作業の流れ、[`コーディング規約.md`](../コーディング規約.md) 実装規約
