# 作業の継続と引き継ぎ

「次」「続けて」は、現在のIssueの残りを進める依頼として扱います。AGENTS、対象Issue/PRの最新記録、ローカルの該当メモ、git差分を確認し、依存条件が整った作業へ進みます。

## 保存する内容

共有する完了状態は対象PRまたはIssueへ記録します。ブランチ未pushの状態や実行中プロセスなど、このcheckoutだけに有効な情報は`artifacts/dev-handoff/<issue番号>.md`へ短く記録できます。Git無視対象なので、他端末には自動で渡りません。

```text
対象Issue / PR:
更新日時・ブランチ・HEAD:
目的 / 完了条件:
今回完了したこと:
変更ファイル / 他者の変更:
確認結果: 実行コマンド・対象HEAD・終了コード・ログの場所
未確認 / 失敗 / 中断した工程:
実行中プロセス・生成途中の出力:
次の一手 / その前提:
```

履歴やログ全文、非公開素材の内容を貼りません。現在の判断に必要な状態と原典の場所だけを記載し、同じIssueのメモを最新状態へ更新します。

## 再開時の確認

- メモのHEAD・ブランチ・差分が現在と一致するか確認します。他エージェントが更新した場合は、変更された箇所だけを読み直します。
- テスト済みの記録は対象HEADと実行範囲を照合します。実行時刻・ログ・終了コードの根拠がない結果は未確認とします。
- 複数エージェントが作業する場合は、担当Issue・ブランチ・編集対象・検証範囲をPR/Issueへ記録し、同じファイルの同時編集を避けます。
- 過去の調査全文の再読は、最新の短い記録では解けない疑問がある場合だけ行います。
