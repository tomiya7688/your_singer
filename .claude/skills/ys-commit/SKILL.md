# ys-commit

1. `git status` と `git diff` を確認し、無関係な変更が混ざっていれば分けるか確認する。
2. 先に `ys-check` 相当の検証が通っているか確認する(未実行なら実行を提案)。
3. ブランチ名 `issue-<番号>-...` から issue 番号を取る。
4. メッセージ形式: `feat(#番号): 日本語の要約` / `fix(#番号): ...` / `docs(#番号): ...`
   (例: `feat(#9): 少数観測音素の補完候補と採用時再検証を追加`)。本文には目的と確認結果を書く。
5. `artifacts/`、生成物、秘密情報をステージしない。
6. コミットは依頼があった場合のみ。pushやPR作成は別途確認する。
