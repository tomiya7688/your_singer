# PRを完成させる

[作業フロー](../../../dev-guidelines/workflow.md#check)の検証からマージまで、該当する工程を実行します。
既存のPRと重複させず、対象headのCIとレビュー条件を確認します。条件が揃わない場合は[引き継ぎ](../../../dev-guidelines/handoff.md)に状況を記録します。
他者のPRを無断でマージしません。
